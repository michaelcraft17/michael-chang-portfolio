# Michael Chang — Portfolio

My personal portfolio site: research, projects, leadership and awards in computer science, AI and community tech.

**Live site:** https://michaelcraft17.github.io/michael-chang-portfolio/

## About

A single static page (`index.html`): hand-written HTML and CSS, no framework and no build step. It's hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
